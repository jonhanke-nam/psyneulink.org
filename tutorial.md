A tutorial is included in the full PsyNeuLink package, available from the PyPi Download or Github Repository.  In addition, the following provides access to a browser-enabled standalone version of the tutorial.

##### Instructions

Go to: [mybinder.org](http://mybinder.org)

Paste into the URL field: [https://github.com/PrincetonUniversity/PsyNeuLink](https://github.com/PrincetonUniversity/PsyNeuLink/)  
In the branch field: master  
In the file path field: tutorial  
Click launch and an interactive notebook will be built in approximately a minute.
