PsyNeuLink now has a graphical user interface (GUI). It is currently in the early stages of development and as such is experimental and relatively feature-sparse. It takes as input a python script that contains a PNL Composition and creates a visualization of it in an interactive workspace.

Planned features include:

- Parameterization of script’s Compositions, Mechanisms, and Projections.
- Live updating of visualization during script editing.
- Full parity with PsyNeuLink library such that the GUI will support any PsyNeuLink script.

[Click here](https://github.com/dillontsmith/PsyNeuLinkView) for the PsyNeuLinkView GitHub repo.

Binary installers are currently available for Windows and Mac. [Click here to download.](https://sourceforge.net/projects/psyneulinkview/files/latest/download)
